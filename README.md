# DOM ↔ OMH baseline workspace

Проект контроля базлайна глобальной работы: одна база, неизменяемые исходные клаймы, явная ветка происхождения на каждом клайме, добавляемые ссылки/комментарии/свойства и независимая приёмка. OMH остаётся владельцем плана, задач и закрытия.

## Статус

Идёт планирование и исследование перед сборкой исполняемого макета. Этот README не является свидетельством реализации. Команды запуска макета появятся после настоящей сборки и проверки.

## Начальные документы

- REQUIREMENTS.md — исходные слова заказчика и подтверждённые требования.
- ADMISSION_AND_INTEGRITY_DESIGN.md — проект протокола внесения и целостности.
- OMH_CODE_REVIEW.md — статический разбор установленного OMH и ограниченная оценка Agora.
- PLAN.md — последовательность аналитик → ресерчер → спецификация → макет → независимые проверки.
- cards/ — технологические карты исполнителей.
- analysis/, research/ — артефакты исследования.
- runtime/logs/ — журналы реальных запусков; не доказательство успешности без артефактов.

## Границы текущего разрешения

Работа только внутри projects/omh-baseline-dom-mcp. Код harness и установленные плагины — read-only reference. Не менять live-конфиги Hermes/OMH; не устанавливать MCP в runtime; не делать push/merge, не создавать автоматически Git-ветки. Использовать безопасные демонстрационные данные и явно маркировать симулированные внешние адаптеры.
