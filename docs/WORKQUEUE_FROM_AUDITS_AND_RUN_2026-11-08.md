## Правила очереди

1. **W1 идёт первой** и блокирует W2: без видимости незавершённого сценарий устаревания нечем проверить — нечего продолжать.
2. **W3/W4/W5 — гигиена прогона**, они не продукт, но без них волна 2 недоказуема. Делаются одним пакетом, до начала W2.
3. **W6 не засчитывается за W1** и наоборот: разные объекты (кеш допуска/доставка ≠ видимость незавершённого).
4. **W7 требует вашего решения** по NU-AU006-02 (живой прогон гейта) — без него часть остаётся политикой.
5. **W8 не начинать**, пока W1–W2 не закрыты: иначе план получит версии, а продолжить работу всё равно будет нельзя.
6. Ни один долг не закрывается по факту карты, прогона или согласия заказчика — только после независимых reviewer и auditor.
