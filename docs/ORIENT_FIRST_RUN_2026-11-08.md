## Препятствия для свежего агента (то, ради чего всё затевалось)
| # | Что | Почему мешает |
|---|---|---|
| H1 | `dom_init` отдаёт `SCOPE_DENIED` на любой неверный `external_work_ref`, без подсказки; `NOT_INITIALIZED` не говорит, чем инициализировать | свежий агент без пакета базлайна не может начать; привязку пришлось читать из кода (это именно E1: пакет базлайна обязан выдаваться до запуска) |
| H2 | `policy_digest` — вычисляемый хеш без способа получить его из самого DOM | агент не может его узнать, не зная фикстур |
| H3 | `dom_resume` по пустой базе не отвечает на вопрос «а где проект?» — только `NOT_READY` и R1/R2 | пустая база и «база не та» выглядят одинаково |
| H4 | Кандидат не содержит читаемого текста в pending (по политике) — нельзя понять, что это за «ожидающий» | задумано (утечка), но нужен безопасный способ описать намерение — `intent`/метка по RS008 |
| H5 | У оркестратора нет роли reviewer в этом подключении | чтобы довести запись до принятой, нужен второй запуск сервера с другой ролью; один агент не может пройти цикл сам (так задумано) |

## Вывод
DOM как память «чего ещё не закончено» теперь работает (W1). Как память «что принято и почему» ещё нет: в базе ни одного допущенного клайма, а запуск без внешней привязки не стартует. Для оркестратора это значит: DOM пока дополняет файлы, а не заменяет их. Закрывать H1/H2/H3 нужно через пакет базлайна (E1) и ответ `NOT_INITIALIZED` с причиной.
